# CS 682: Modern Introduction to Neural Networks

## Implementation and learning guidance

Complete concrete, reproducible experiments before expanding scope. For each substantive implementation, explain its purpose, inputs, outputs, dimensions, mathematical assumptions, relevant theory, practical applications, and verification. Use the CS 682 lecture slides and publicly available course website first, then original papers and university resources as needed. Cite exact sources when available and disclose when unavailable. Do not assume familiarity with later lectures; introduce prerequisites only when needed. Explain transferable practitioner skills and interview concepts without turning every task into a full lecture.

Keep changes minimal, modular and testable. Report actual commands, observed results and limitations separately from expectations. Never present synthetic tests as real-race evidence. Preserve decision-time feature alignment and avoid target leakage. Keep the CS 682 team project separate from other F1 or research repositories. Do not add architectures merely because they appear in course material.

## Immediate milestone

Prioritize the Silverstone 2019 proof of concept: run the existing smoke tests, verify actual FastF1 data extraction, validate the simulator intervention with a recorded decision trace, then document reproducible evidence. Do not claim completion if external data or simulator execution fails. Follow the repository contribution guidance and preserve teammates' changes.
